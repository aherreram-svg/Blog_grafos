Representación de Grafos: Lista y Matriz de Adyacencia

Aprende las dos formas principales de implementar grafos en memoria

¿Cómo representar un grafo en memoria?

Una de las decisiones más importantes al trabajar con grafos es elegir cómo representarlos en la memoria del computador. La forma en que representemos el grafo afectará directamente la eficiencia espacial y temporal de nuestros algoritmos.

Existen dos representaciones principales que se utilizan en la programación:

  1. Lista de Adyacencia: Eficiente en espacio para grafos dispersos
  2. Matriz de Adyacencia: Eficiente en tiempo para consultar conexiones

La elección entre una u otra depende de las características de nuestro problema y qué operaciones realizaremos con mayor frecuencia.

Lista de Adyacencia

¿Qué es?

Una lista de adyacencia es una forma de representar un grafo donde cada nodo tiene una lista que contiene todos los nodos con los que está conectado.

La estructura se puede implementar usando un diccionario (objeto en JavaScript) donde:

  • Clave: El identificador del nodo
  • Valor: Una lista (array) de sus nodos vecinos

Ejemplo de Implementación

// Grafo no dirigido con lista de adyacencia const grafo = { 'A': ['B', 'C'], 'B': ['A', 'D', 'E'], 'C': ['A', 'F'], 'D': ['B'], 'E': ['B', 'F'], 'F': ['C', 'E'] }; // Acceder a los vecinos de un nodo console.log(grafo['A']); // ['B', 'C'] // Agregar una conexión grafo['A'].push('D'); // A ahora conecta con D

Para Grafos Dirigidos

En un grafo dirigido, la lista de adyacencia solo incluye los nodos a los que se puede llegar directamente desde cada nodo.

// Grafo dirigido: A → B significa que A apunta a B const grafoDigirido = { 'A': ['B', 'C'], // A apunta a B y C 'B': ['D'], // B apunta a D 'C': ['F'], // C apunta a F 'D': [], // D no apunta a nadie 'E': ['A'], // E apunta a A 'F': ['E'] // F apunta a E };

Para Grafos Ponderados

Para grafos ponderados, en lugar de almacenar solo el nodo vecino, almacenamos un objeto con el nodo y su peso.

// Grafo ponderado const grafoPonderado = { 'A': [ { nodo: 'B', peso: 5 }, { nodo: 'C', peso: 3 } ], 'B': [ { nodo: 'A', peso: 5 }, { nodo: 'D', peso: 7 } ], 'C': [ { nodo: 'A', peso: 3 }, { nodo: 'F', peso: 8 } ] // ... más nodos };

Ventajas de Lista de Adyacencia

  • ✅ Eficiente en espacio: Solo almacena las aristas que existen (ideal para grafos dispersos)
  • ✅ Operaciones de iteración rápidas: Acceso inmediato a los vecinos de un nodo
  • ✅ Flexible: Fácil de modificar, agregar o eliminar nodos y aristas

Desventajas de Lista de Adyacencia

  • ❌ Verificación de aristas lenta: Necesita iterar la lista para verificar si existe una arista
  • ❌ Eliminación de aristas puede ser lenta: Requiere búsqueda en la lista

Matriz de Adyacencia

¿Qué es?

Una matriz de adyacencia es una matriz (tabla 2D) que representa el grafo. Las filas y columnas representan los nodos, y cada celda [i][j] indica si existe una arista del nodo i al nodo j.

Ejemplo de Implementación

// Grafo no dirigido con matriz de adyacencia // Nodos: A(0), B(1), C(2), D(3), E(4), F(5) const matriz = [ [0, 1, 1, 0, 0, 0], // A: conectado a B, C [1, 0, 0, 1, 1, 0], // B: conectado a A, D, E [1, 0, 0, 0, 0, 1], // C: conectado a A, F [0, 1, 0, 0, 0, 0], // D: conectado a B [0, 1, 0, 0, 0, 1], // E: conectado a B, F [0, 0, 1, 0, 1, 0] // F: conectado a C, E ]; // Verificar si existe arista A-B (0-1) console.log(matriz[0][1]); // 1 (sí existe) // Verificar si existe arista A-D (0-3) console.log(matriz[0][3]); // 0 (no existe) // Agregar arista A-D matriz[0][3] = 1; matriz[3][0] = 1; // En grafo no dirigido, hacerlo en ambas direcciones

Para Grafos Dirigidos

En un grafo dirigido, la matriz es asimétrica. matriz[i][j] = 1 significa que hay una arista de i a j, pero matriz[j][i] puede ser diferente.

// Grafo dirigido // A → B, A → C, B → D, etc. const matrizDigirida = [ [0, 1, 1, 0, 0, 0], // A apunta a B, C [0, 0, 0, 1, 0, 0], // B apunta a D [0, 0, 0, 0, 0, 1], // C apunta a F [0, 0, 0, 0, 0, 0], // D no apunta a nadie [1, 0, 0, 0, 0, 0], // E apunta a A [0, 0, 0, 0, 1, 0] // F apunta a E ];

Para Grafos Ponderados

En lugar de 0 y 1, almacenamos el peso de la arista. 0 o infinito (∞) indica que no hay arista.

const matrizPonderada = [ [0, 5, 3, ∞, ∞, ∞], // A-B: 5, A-C: 3 [5, 0, ∞, 7, ∞, ∞], // B-A: 5, B-D: 7 [3, ∞, 0, ∞, ∞, 8], // C-A: 3, C-F: 8 [∞, 7, ∞, 0, ∞, ∞], // D-B: 7 [∞, ∞, ∞, ∞, 0, 1], // E-F: 1 [∞, ∞, 8, ∞, 1, 0] // F-C: 8, F-E: 1 ];

Ventajas de Matriz de Adyacencia

  • ✅ Búsqueda rápida de aristas: O(1) para verificar si existe una arista
  • ✅ Adición y eliminación de aristas rápida: O(1)
  • ✅ Algunos algoritmos más eficientes: Floyd-Warshall funciona bien con matrices

Desventajas de Matriz de Adyacencia

  • ❌ Uso excesivo de memoria: O(n²) incluso para grafos dispersos
  • ❌ Iteración de vecinos lenta: Debe recorrer toda la fila para encontrar vecinos
  • ❌ No ideal para grafos grandes: Si el grafo tiene 10,000 nodos, necesita una matriz de 100 millones de celdas

Comparación: Lista vs Matriz de Adyacencia

Operación Lista de Adyacencia Matriz de Adyacencia
Espacio O(V + E) O(V²)
Verificar arista (u,v) O(grado(u)) O(1)
Obtener vecinos de u O(grado(u)) O(V)
Agregar arista O(1) O(1)
Eliminar arista O(grado(u)) O(1)
Mejor para Grafos dispersos Grafos densos

¿Cuál Usar?

Usa Lista de Adyacencia cuando:

  • 💚 El grafo tiene pocas aristas en comparación con V² (grafo disperso)
  • 💚 Necesitas iterar sobre los vecinos de un nodo con frecuencia
  • 💚 Necesitas ahorrar memoria
  • 💚 Trabajas con redes sociales, la web, o sistemas reales (generalmente dispersos)

Usa Matriz de Adyacencia cuando:

  • 🔵 El grafo tiene muchas aristas en comparación con V² (grafo denso)
  • 🔵 Necesitas verificar si existe una arista específica muy frecuentemente
  • 🔵 Usarás algoritmos que necesitan acceso O(1) a cualquier arista
  • 🔵 El número de nodos es relativamente pequeño

Resumen

La representación de un grafo es fundamental para su implementación eficiente. Las dos opciones principales son:

  • Lista de Adyacencia: Ideal para grafos dispersos, usa O(V + E) de espacio, excelente para iterar vecinos
  • Matriz de Adyacencia: Ideal para grafos densos, usa O(V²) de espacio, búsqueda de aristas en O(1)

La elección depende de la naturaleza de tu problema y qué operaciones son más frecuentes. En la mayoría de casos reales, la lista de adyacencia es la opción preferida.
