Algoritmos Fundamentales de Recorrido: BFS y DFS

Domina los dos algoritmos más importantes para explorar grafos

📋 Contenido de este artículo

  • ¿Por qué recorrer grafos?
  • BFS (Breadth-First Search)
  • DFS (Depth-First Search)
  • Comparación y Aplicaciones

¿Por qué recorrer grafos?

Uno de los problemas fundamentales al trabajar con grafos es poder visitarlos de manera sistemática, es decir, pasar por todos sus nodos (o los conectados) en un orden específico. Esto es necesario para:

  • Buscar un nodo específico: ¿Existe una página web con ese contenido?
  • Verificar conectividad: ¿Están conectados todos los nodos?
  • Encontrar caminos: ¿Cuál es el camino más corto entre dos ciudades?
  • Análisis de red: ¿Cuán relacionados están los usuarios en una red social?
  • Resolver problemas complejos: Muchos problemas complejos requieren recorrer un grafo

Los dos algoritmos de recorrido más importantes son:

  • BFS (Breadth-First Search): Búsqueda en Amplitud
  • DFS (Depth-First Search): Búsqueda en Profundidad

BFS (Breadth-First Search) - Búsqueda en Amplitud

Concepto Fundamental

BFS es un algoritmo que recorre el grafo nivel por nivel. Comienza desde un nodo inicial y explora todos sus vecinos antes de pasar a los vecinos de esos vecinos.

Imagina que arrojas una piedra en un estanque: las ondas se expanden hacia afuera, primero alcanzando los puntos más cercanos, luego los más lejanos. BFS funciona de manera similar.

Algoritmo Paso a Paso

  1. Comienza con un nodo inicial
  2. Coloca el nodo inicial en una cola (FIFO)
  3. Mientras la cola no esté vacía:
    1. Extrae el primer nodo de la cola
    2. Procesa el nodo (visítalo)
    3. Agrega todos sus vecinos no visitados a la cola

Implementación en JavaScript

function BFS(grafo, nodoInicial) { const visitados = new Set(); const cola = [nodoInicial]; const orden = []; visitados.add(nodoInicial); while (cola.length > 0) { // Extrae el primer nodo de la cola const nodo = cola.shift(); orden.push(nodo); // Explora todos los vecinos for (const vecino of grafo[nodo]) { if (!visitados.has(vecino)) { visitados.add(vecino); cola.push(vecino); } } } return orden; } // Uso: const grafo = { 'A': ['B', 'C'], 'B': ['A', 'D', 'E'], 'C': ['A', 'F'], 'D': ['B'], 'E': ['B', 'F'], 'F': ['C', 'E'] }; console.log(BFS(grafo, 'A')); // Resultado: ['A', 'B', 'C', 'D', 'E', 'F']

Características de BFS

  • Complejidad Temporal: O(V + E) donde V = vértices, E = aristas
  • Complejidad Espacial: O(V) para la cola y el set de visitados
  • Estructura de datos: Cola (FIFO)
  • Orden de visita: Nivel por nivel (amplitud primero)

Ventajas de BFS

  • ✅ Encuentra el camino más corto en grafos sin pesos
  • ✅ Completo: Siempre encuentra una solución si existe
  • ✅ Óptimo para problemas de distancia mínima

Desventajas de BFS

  • ❌ Usa más memoria que DFS (almacena todos los nodos de un nivel)
  • ❌ Más lento para ciertos tipos de grafos

DFS (Depth-First Search) - Búsqueda en Profundidad

Concepto Fundamental

DFS es un algoritmo que recorre el grafo explorando lo más profundo posible antes de retroceder. Comienza desde un nodo inicial y continúa explorando cada rama hasta el final antes de pasar a la siguiente rama.

Imagina que entras en un laberinto y siempre tomas un pasillo hasta el final, luego retrocedes para probar otra ruta. Así funciona DFS.

Algoritmo Paso a Paso (Versión Iterativa)

  1. Comienza con un nodo inicial
  2. Coloca el nodo inicial en una pila (LIFO)
  3. Mientras la pila no esté vacía:
    1. Extrae el último nodo de la pila
    2. Procesa el nodo (visítalo)
    3. Agrega todos sus vecinos no visitados a la pila

Implementación en JavaScript (Iterativa)

function DFS(grafo, nodoInicial) { const visitados = new Set(); const pila = [nodoInicial]; const orden = []; while (pila.length > 0) { // Extrae el último nodo de la pila const nodo = pila.pop(); if (!visitados.has(nodo)) { visitados.add(nodo); orden.push(nodo); // Agrega todos los vecinos a la pila for (const vecino of grafo[nodo]) { if (!visitados.has(vecino)) { pila.push(vecino); } } } } return orden; } // Uso: const grafo = { 'A': ['B', 'C'], 'B': ['A', 'D', 'E'], 'C': ['A', 'F'], 'D': ['B'], 'E': ['B', 'F'], 'F': ['C', 'E'] }; console.log(DFS(grafo, 'A')); // Resultado posible: ['A', 'C', 'F', 'E', 'B', 'D']

Implementación Recursiva de DFS

DFS también puede implementarse recursivamente, lo que es más elegante:

function DFS_Recursivo(grafo, nodo, visitados = new Set(), orden = []) { visitados.add(nodo); orden.push(nodo); for (const vecino of grafo[nodo]) { if (!visitados.has(vecino)) { DFS_Recursivo(grafo, vecino, visitados, orden); } } return orden; } // Uso: console.log(DFS_Recursivo(grafo, 'A'));

Características de DFS

  • Complejidad Temporal: O(V + E) igual que BFS
  • Complejidad Espacial: O(V) para la pila y el set de visitados
  • Estructura de datos: Pila (LIFO) o recursión
  • Orden de visita: Profundidad primero

Ventajas de DFS

  • ✅ Usa menos memoria que BFS (pila más pequeña)
  • ✅ Más eficiente en ciertos problemas (ciclos, componentes conectadas)
  • ✅ Útil para ordenamiento topológico y análisis de conectividad

Desventajas de DFS

  • ❌ No encuentra necesariamente el camino más corto
  • ❌ Puede ser menos intuitivo que BFS

Complejidad Espacial O(V) - Puede ser alta O(V) - Generalmente menor

Aplicaciones Prácticas

Cuándo usar BFS

  • 🔍 Encontrar el camino más corto: GPS, redes
  • 🔍 Análisis de componentes conectadas: Redes sociales
  • 🔍 Buscar en amplitud: Motores de búsqueda web
  • 🔍 Bipartición de grafos: Coloring de grafos
  • 🔍 Buscar por niveles: Estructura de árbol

Cuándo usar DFS

  • 🎯 Ordenamiento Topológico: Dependencias de tareas
  • 🎯 Detección de ciclos: Verificar dependencias circulares
  • 🎯 Componentes fuertemente conectadas: Análisis de redes
  • 🎯 Backtracking: Resolver laberintos, Sudoku
  • 🎯 Buscar en laberintos: Juegos, navegación

Resumen

BFS y DFS son los dos algoritmos fundamentales para recorrer grafos. Ambos tienen complejidad O(V + E), pero difieren en su enfoque:

  • BFS (Breadth-First Search): Explora nivel por nivel usando una cola. Ideal para encontrar el camino más corto en grafos sin pesos.
  • DFS (Depth-First Search): Explora profundidad primero usando una pila o recursión. Ideal para detectar ciclos, ordenamiento topológico y problemas de backtracking.

Dominar estos dos algoritmos es fundamental para resolver problemas más complejos con grafos, como encontrar componentes conectadas, ordenamiento topológico, y algoritmos avanzados como Dijkstra (basado en BFS) o búsqueda por profundidad en análisis de conectividad.
